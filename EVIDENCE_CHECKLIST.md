# Assignment 3 evidence checklist

Take screenshots from your own Windows execution. Save them under the exact filenames in `EVIDENCE_FILENAMES.md`.

- Task01: program summary and rainfall benchmark output; keep `rainfall_benchmark.csv`.
- Task02: bad/good grid, `is` identity, copy examples, and memory/time results.
- Task03: frequency/top-k and district grouping results, plus benchmark output; keep `complaints_benchmark.csv`.
- Task04: all set operation results, Venn diagram, membership and intersection timing output; keep `sets_benchmark.csv`.
- Task05: three methods agree, alarm minutes, all-valid/all-invalid checks and benchmark/memory output; keep `sensor_benchmark.csv`.
- Task06: neat timetable, station/day result, unknown station test, indexed/non-indexed timing and index memory; keep `timetable_benchmark.csv`.
- Task07: hand-checked merge result, 1,000 / 100,000 measurements, pairwise comparison / extrapolation explanation; keep `contact_benchmark.csv`.

A terminal screenshot alone is not enough where the assignment requests raw timings, memory sizes, call/operation counts or a written explanation. Keep the CSV files and analysis notes as well.
